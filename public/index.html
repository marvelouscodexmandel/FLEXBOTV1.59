Security checklist

Recommended
✓
Keep credentials server-side

Store access tokens and app secrets only in Render Environment settings. Never put them in frontend code or screenshots.

2
Rotate credentials if exposed

If a token was shared publicly, revoke it in Meta and create a replacement before updating Render.

3
Verify webhook signatures

Validate Meta's X-Hub-Signature-256 using the app secret, and use a strong, private webhook verification token.

4
Protect admin endpoints

Require authentication and admin authorization; use HTTPS and avoid logging tokens or private message contents.

5
Review account access

Enable two-factor authentication on GitHub, Render, and Meta, and remove collaborators you do not recognize.
